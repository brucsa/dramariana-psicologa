# 🌟 Landing Page - Psicóloga Infantil
Este projeto é uma landing page fictícia para uma psicóloga infantil chamada Dra. Mariana Souza. A página foi projetada com foco em usabilidade e uma experiência amigável para os usuários, utilizando práticas modernas de design e desenvolvimento.

## 📸 Preview
🔗 [Acesse aqui a landing page](https://brucsa.github.io/dramariana-psicologa)

## 📋 Funcionalidades
### Menu Hamburguer (Mobile):
Um menu de navegação que se adapta aos dispositivos móveis. O botão hamburguer abre e fecha o menu com uma animação suave, e o menu pode ser fechado ao clicar fora dele.
### Responsividade:
A landing page se adapta perfeitamente a diferentes tamanhos de tela, oferecendo uma ótima experiência tanto para usuários de dispositivos móveis quanto desktop.
### Design Moderno e Limpo:
Utilização de cores suaves e tipografia agradável para criar uma atmosfera acolhedora e profissional.

## 🛠️ Tecnologias Utilizadas
### HTML:
Estruturação da página com tags semânticas e formulários.
### CSS:
Estilos da página, incluindo layouts responsivos e animações.
### JavaScript:
Funcionalidade do menu hambúrguer para dispositivos móveis, com a implementação de fechamento automático ao clicar fora do menu.
